# MyoMetrics — EMG Project

**University of Bath | Year 2 Engineering Project Week**

MyoMetrics is a five-person team investigating how **electromyography (EMG)** can be used to measure muscle activation. Using a **MyoWare 2.0** sensor and **MATLAB**, we aim to collect EMG data, reduce noise, extract useful features and compare muscle activity under different contraction conditions.

## Our approach

1. **Acquire:** Record an EMG signal from at least one participant, subject to kit availability.
2. **Process:** Import the data into MATLAB and apply suitable filtering or envelope analysis, accounting for any processing already performed by the sensor.
3. **Analyse:** Compare muscle activation across up to three contraction conditions and visualise the findings.
4. **Present:** Explain the methods, results and a potential real-world use to a non-technical audience.
